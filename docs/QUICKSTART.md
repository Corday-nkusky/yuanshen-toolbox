# YuanshenToolbox · 速览

> 中文名：元神工具箱。

## 下载

**仓库**：<https://github.com/Corday-nkusky/yuanshen-toolbox>
**直接下载**：<https://github.com/Corday-nkusky/yuanshen-toolbox/releases/latest>
→ 取 `YuanshenToolbox-v<版本号>.exe`（单文件，文件名带版本号，约 27 MB）。
免安装、不需要 Python，双击即用。

## 干什么用

读取本机扫雷录像（元扫雷 `.evf` / 阿比特 `.avf`），统计并展示：

1. **PB 表** —— 每个（级别 × 3BV）下用时最短的完成局，分全PB / NF PB 两张榜；
   登录后与网站已有 PB 取并集
2. **前端成绩** —— 初级 / 中级 / 高级各自 time、3BV/s、stnb 的前五局
3. **NF / FL 判定** —— 重演录像点击流算 `rce`，右键有效插旗数为 0 即 NF
4. **上传** —— 把本地完成局传到 [开源扫雷网](https://openms.top)，自动跳过网站上已有的

纯本地只读工具：不上传录像（除你主动发起）、不起后台服务、不写系统目录。
所有运行数据在 exe 同目录的 `YuanshenToolbox-data\` 里，删掉即恢复全新状态。
旧版的 `元神工具箱-data\` 会在首次启动时自动改名过来。

## 怎么用

1. **放**：把 exe 放到元扫雷的 `Metasweeper<版本号>` 目录里（`replay` 的上一级）。
   不知道在哪：元扫雷菜单「查看 → 录像目录」（快捷键 `W`），再上一级就是。
2. **跑**：双击。程序优先认 exe 旁边的 `replay`；找不到会自己搜
   `%APPDATA%` / `%LOCALAPPDATA%` 下的 `Metasweeper*`；都没有才让你手动选目录。
   选一次就记住。
3. **等**：首次扫描要逐局重演录像，2 万局约 3 分钟（底部有进度条和剩余时间）。
   之后走缓存，一秒级。
4. **看**：页签切换 —— 概览 / PB 表 / 前端成绩 / 上传。
   点表头排序，双击某行复制该录像的完整路径。
5. **上传**（可选）：到「上传」页 →「登录…」输账号密码验证码（勾「保持登录 90 天」，
   之后只靠 Cookie，不用再输密码）→ 选范围 →「上传全部未传」。
   上传前会弹确认框列出这一批，Esc 取消、回车确认。上传不会重复，断点可续。

阿比特的录像默认**不自动加入**（阿比特目录里常有从网上下载的别人的录像，
自动收进来会把别人的成绩算成你的）。要加就点「路径 (N)…」→「添加目录…」，
加之前会确认「这里每一条都算你自己打的」。

## 常见问题

| 情况 | 处理 |
|---|---|
| 数据算错了 / 换了录像 | 「重新扫描」；仍不对 →「诊断…」→「清空缓存」再扫 |
| exe 放在 `C:\Program Files` 等不可写位置 | 数据自动落到 `%APPDATA%\YuanshenToolbox\`，「诊断…」里会写明 |
| 上传后不进榜、网站状态显示 `d` | 录像标识与账号「标识管理」里登记的不一致，改对标识再传 |
| 要报问题 | 「诊断…」→「导出诊断包…」，zip 里是系统信息、配置、日志（不含密码与 Cookie 密文正文） |
